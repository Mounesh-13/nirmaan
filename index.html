Ephemeral, Zero-Persistence Architecture

Why Zero-Persistence?

Computer labs, hackathons, and competitive programming sessions need instant, low-friction sharing without leaving student code stored on a persistent database. When the room closes, everything is gone.

Keyboard Shortcuts & Tricks

  • Ctrl + Enter: Broadcast message or code immediately.
  • Tab: Indent 2 spaces inside the Code Drop editor (does not lose focus).
  • Shift + Tab: Dedent code block.
  • Esc: Close any active modal.
